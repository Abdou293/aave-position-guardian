# خطة مشروع Aave Position Guardian

نظام **للقراءة فقط وغير وصائي (non-custodial)**: يراقب مراكز الاقتراض على Aave V3 وينبّه صاحبها مبكرًا عبر تيليجرام ولوحة تحكم.
لا يطلب ولا يخزّن أي مفتاح خاص أو عبارة استرداد، ولا يرسل أي معاملة أبدًا.

## المراحل

1. **الأساس:** المستودع، وحارس الأسرار gitleaks، والتحقق من عناوين العقود على البلوكتشين. ✅
2. **قراءة البيانات:** واجهة مصدر بيانات موحدة، وقارئ حقيقي عبر Multicall3، ومصدر محاكاة، واختبارات.
3. **محرك التنبيهات:** عتبات، وcooldown، وhysteresis، ومنع التكرار، ورسالة التعافي.
4. **تيليجرام وقاعدة البيانات:** حفظ المحافظ والإعدادات واللقطات، وإرسال لا يتكرر بعد إعادة التشغيل.
5. **لوحة التحكم:** رسم تاريخ Health Factor، وسجل التنبيهات، وصفحة صحة الشبكات، والوضع التجريبي.
6. **التحقق والنشر:** اختبار على fork للقراءة فقط، ثم نشر العرض التجريبي مجانًا.
7. **النشر على GitHub:** README، والرخصة، وإخلاء المسؤولية، وفيديو، ودليل Upwork.

## هيكل المجلدات

```
aave-position-guardian/
├── src/                      ← الخادم (Fastify) + البوت + المُجدوِل
│   ├── chain/                ← الشبكات والقراءة من البلوكتشين (viem + Multicall3)
│   ├── datasources/          ← الواجهة الموحدة + المصدر الحقيقي + المحاكاة
│   ├── alerts/               ← محرك التنبيهات
│   ├── risk/                 ← تقدير "ماذا لو" (مع المعادلة وحدودها)
│   ├── db/                   ← طبقة الوصول للبيانات (SQLite ← PostgreSQL)
│   ├── bot/                  ← بوت تيليجرام (grammY)
│   └── api/                  ← واجهات HTTP
├── tests/                    ← الاختبارات + fixtures مسجلة
├── dashboard/                ← لوحة التحكم (Next.js)
├── config/addresses.json     ← عناوين موثقة على البلوكتشين (يولّدها السكربت)
├── scripts/                  ← سكربتات مساعدة (التحقق من العناوين…)
├── docs/                     ← التوثيق
└── .githooks/                ← حراس gitleaks قبل الـ commit والـ push
```

## القرارات

- العمل مباشرة على Windows، وWSL2 فقط لأداة الـ fork في المرحلة 6.
- viem، وFastify، وgrammY، وNext.js، وVitest.
- RPC عامة مجانية افتراضيًا، ويمكن تجاوزها عبر `.env`.
- قاعدة SQLite محليًا، وPostgreSQL (Neon المجاني) للنسخة المنشورة، لأن قرص Render المجاني لا يحفظ الملفات.
